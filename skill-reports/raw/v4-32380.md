I checked the change against the drawing code. I couldn't run anything because matplotlib isn't importable in this environment, and the GitHub API returned 403, so I couldn't read the PR thread either. The verdict below comes from reading the code only.

**What the PR does:** `FigureImage` now sets its transform to `IdentityTransform()` explicitly when it is created. Before this, if you removed a `figimage` and put it back with `fig.add_artist(im)`, `add_artist` saw that no transform had been set and gave it `transSubfigure`. The image was then drawn in the wrong place and at the wrong size.

**Why the fix is right:**
- **The bug is real.** `_ImageBase._make_image` adds `self.get_transform()` to the image's own pixel placement (`lib/matplotlib/image.py:445-450`). `FigureImage.make_image` already places the image in pixels using `ox`/`oy`. Adding `transSubfigure` on top would stretch the image across the whole figure.
- **No change on the normal path.** `Artist.get_transform()` already falls back to `IdentityTransform()` when nothing is set, so plain `fig.figimage(...)` draws exactly as before.
- **A user's `transform=` still wins.** The new `set_transform` runs before `self._internal_update(kwargs)` (`lib/matplotlib/image.py:1414` vs `:1417`), so a transform passed to `figimage` overrides it, as it did on `main`.
- **The only visible difference** is that `is_transform_set()` now returns `True` for a `FigureImage`. Nothing in the library reads that except `add_artist`, which is the point of the fix.
- **It also covers building `FigureImage(fig)` by hand** and passing it to `fig.add_artist`. That path had the same bug.

**The test** (`lib/matplotlib/tests/test_image.py:87`): it uses `check_figures_equal` with no new baseline image. The reference figure is a plain `figimage`. The test figure does remove, then `add_artist`. On `main` the re-added image picks up `transSubfigure`, so the test should fail there and pass with the fix.

No API-change note or stub update is needed: there is no signature change, and this is a bug fix. The branch is up to date with `origin/main`.
